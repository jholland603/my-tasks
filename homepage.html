Google requires this page to be served over http://localhost for Gmail sign-in.
It's a one-time, one-command setup — no installs needed if you have Python or Node.

Step 1 — Serve this file locally (run once in Terminal / Command Prompt):

cd ~/Downloads && python3 -m http.server 8080

Then open http://localhost:8080/homepage.html in your browser and set that as your homepage.

No Python? Use Node: npx serve . -p 8080  ·  Or just set Chrome's homepage to this localhost URL after starting the server.

Step 2 — Create a Google OAuth Client ID (free, one-time):

1. Go to console.cloud.google.com/apis/credentials
2. Create Credentials → OAuth 2.0 Client ID → Web application
3. Authorized JavaScript origins: add http://localhost:8080
4. No redirect URI needed. Copy your Client ID.
